PNG・JPEG・WebP・SVG に対応。正方形で、できれば 512px 以上の画像がきれいに仕上がります。画像は端末の中だけで処理され、サーバーには送られません。

アプリに反映するには
  1. 上の「すべてまとめて ZIP」をダウンロードして展開します。中の public フォルダは、アプリの public フォルダと同じ並びです。
  2. favicon.png と apple-touch-icon.png (public/)と、icon-192.png・icon-512.png・maskable-512.png(public/icons/)を、同じ名前のファイルに上書きします。
  3. 変更を GitHub に push すると、Vercel が自動で公開します。スマートフォンでは、一度ホーム画面のアイコンを削除して追加し直すと新しいアイコンになります。

設定内容(色・余白・形)と選んだ画像は、この端末のブラウザにだけ保存されます。他の端末や他の管理者とは共有されません。
